# Real attestation chain fixtures

These chains and their expected-value JSON files are copied unmodified from
Google's [android/keyattestation](https://github.com/android/keyattestation)
`testdata/` directory (commit `621149c4ebaeeea844d6f43098687c73c4d370a3`),
licensed under the Apache License 2.0. File names flatten `device/sdk/name`
into `device_sdk_name`.

They contain no end-user data: they were generated by Google on test devices.
