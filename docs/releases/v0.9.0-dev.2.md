### New: downloadable report file (Run 31)
The scanner exports a full **results and debug file** instead of sharing JSON text:
- **Save report file:** the Android file picker opens, so you can choose Downloads or Drive.
- **Share report file:** sends a real `.json` attachment by mail, chat and so on.
- **Where:** in the Scan tab, also after a failed scan, and in the Server tab.

The file (`cyclone-scan-debug-report` v1) contains:
- `summary`: the verdict, how many checks completed and how many could not be scanned.
- `notScanned`: every check, verification layer, comparison, scan phase, server evidence item and biometric step that could **not** be scanned. Each comes with its state, reason, a plain explanation and a developer hint.
- `errors` and `phases`: what failed and how long each step took, with sanitized exception messages. These were previously discarded: hardware key generation, the revocation download and native library loading.
- `app` and `device`: version, APK SHA-256, installer, debuggable flag, Android version, security patch, ABIs and StrongBox support.
- `localScan`: the complete scan report. `server` and `biometric` are included when those tabs were run.

It contains no serial number, IMEI, account data, server address, tokens or file paths.
