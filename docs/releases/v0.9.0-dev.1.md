### Download
- `cyclone-scanner-0.9.0-dev.1.apk`: the scanner test app. Install it on an Android 8+ phone; allow installs from this source when Android asks.

- `build-evidence.json`, `scanner-assurance-manifest.json` and `SHA256SUMS`: the exact revision, digests, toolchain and signer.

### Identity
- APK and file digests: the attached `SHA256SUMS` and `build-evidence.json`, produced by the release build.
- Signed with the **public development key**: certificate SHA-256 `412b9e05c1418d4e5e1e0f86ee21687569b4623231f951e5cf6a8e67cc469416`, see [android/signing](https://github.com/premiumcentraal-boop/Cyclone-scan/tree/run-19b-dev-open-source/android/signing).

  - Never trust it in a production verification policy.
- Built by the `Dev pre-release` workflow from the code at this tag; the exact revision is in `build-evidence.json`.

### What it does
- **Scan tab:** a local diagnostic of the phone. Nothing leaves the phone.
- **Server tab:** the full flow against a [Device Trust Service](https://github.com/premiumcentraal-boop/Cyclone-scan/tree/run-19b-dev-open-source/service) that you run yourself:
  - enrollment
  - signed actions
  - server-verified scan with history
  - key rotation
  - a shareable lab record
